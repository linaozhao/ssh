# CBM MAD 漂移诊断标注指南

## 1. 适用范围

标注对象是智能体的公开答案与简短解释，不推断隐藏思维、心理状态或因果机制。每个阶段的标准仅由该阶段已经生效的正式证据和固定规则决定；未来证据不得用于评价过去发言。

任务答案是“截至当前尚未被排除的所有候选人”。已知违反任一必要条件时排除；未知不等于违反；尚未排除不等于已证实完全合格。明确 `CORRECTION` 只撤销其点名的旧证据。同伴发言是意见，不是正式证据。

## 2. 先标结果，再标内容

1. 记录该发言的集合答案是否可识别。
2. 对照当前标准集合，记录错误加入和错误排除。
3. 阅读解释，只在存在明确文本证据时建立内容事件。
4. 答案错误不自动推出某一种内容偏离；答案正确也不能掩盖解释中的明确错误事实。

## 3. 内容类别

- `factual_deviation`：发言明确认可的主张与当前有效事实冲突，或把未知属性断言为已知。
- `rule_deviation`：发言明确增加、删除、放宽或替换固定规则。
- `inference_application_error`：发言公开认可的前提不能支持其局部结论，例如承认候选人违反必要条件却仍称其未被排除。
- `unresolved`：观察到问题，但现有文本不足以可靠细分。

允许多标签。仅仅没有提及某条规则，不足以标为规则偏离。

## 4. 立场与引用

引用同伴的错误主张、提出假设、明确反驳或表达不确定性，不等于作者认可该主张。只给作者实际认可的可核查主张加内容标签。引文必须逐字来自当前发言，并记录字符起止位置。

## 5. 过程状态

- `initial_error`：该智能体在可观察序列中的首条输出已经有错。
- `newly_introduced`：此前相邻输出正确，本次首次出现错误。
- `persistent`：相同对象上的错误在相邻输出持续。
- `corrected`：此前错误在本次消失，且本次结果正确。
- `recurrence`：错误消失后在后续再次出现。
- `reasonable_update`：正式证据更新后，答案随新标准状态合理改变。
- `correct_maintenance`：答案保持正确。
- `uncertain`：格式、证据或边界情况不足以判断。

“首次观察到偏离”与“由明确的此前正确判断变为错误”必须分开；后者需要前序正确输出证据。

## 6. 事件边界

同一智能体、同一候选人或规则对象、同一错误主张的连续重复可合并为一个事件，并保留每次持续记录。错误消失后再次出现应建立复发记录。不同智能体的对应事件分别记录，可通过 `related_event_ids` 关联。

## 7. 边界例

- 正例：有效证据明确说 A 周一不可用，发言断言“A 周一可用”，标 `factual_deviation`。
- 正例：发言称“未知即不满足”，标 `rule_deviation`；若据此排除候选人，也可加 `inference_application_error`。
- 反例：发言写“同伴声称 A 可用，但证据显示并非如此”，错误短语处于被反驳立场，不标事实偏离。
- 边界：答案集合错误，但解释仅重复最终集合、未暴露原因。可记录结果错误；内容类别用 `unresolved` 或不建立内容事件，并说明原因。
- 合理更新：T4 的更正撤销旧证据，模型改变答案以匹配新标准，不标漂移。

## 8. 独立标注流程

两名标注者分别填写各自模板，不查看 Judge 预标注。保留两份原始结果，再由第三份 adjudication 文件记录裁决。可新增自动系统未发现的事件，也可明确标记整条轨迹无内容偏离。未来阶段折叠内容仅供后续阶段使用，不得回看用于修改早期判断。

本轮没有独立参考标签时，检测和分类 precision/recall/F1 状态统一为“尚未评估”。
