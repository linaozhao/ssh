# Discarded protocol-v0 responses

These records were produced during the initial preflight and the beginning of
an interrupted formal resume. Dynamic user messages included internal
condition identifiers (`C_clean`, `E_noise`, or `D_update`) in their headings.
This did not reveal an oracle or Gold answer, but `E_noise` disclosed a
diagnostic condition label and violated the frozen-input policy.

The run was stopped, preserved here for auditability, and excluded from every
formal result. Prompt version `cbm_attr_set_v1.1` uses the neutral heading
`Evidence update, round N` for all three dynamic conditions. The corrected
preflight and formal experiment use a new prompt fingerprint.
